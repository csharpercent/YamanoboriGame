## review-checklist.md（案）

### セルフリビュー・チェックリスト

コミット・PR作成前に、必ず以下の項目を一つずつ確認！

#### **1. 機能面**
- [ ] 期待通りに動く？
- [ ] エッジケース（端のケース）は試した？
- [ ] 前の機能は壊れてない？

#### **2. コード品質**
- [ ] `coding-style.md` に従ってる？
- [ ] 変数名はわかりやすい？
- [ ] コメントは「なぜ？」を説明してる？

#### **3. Git運用**
- [ ] コミットメッセージは `commit-guidelines.md` 準拠？
- [ ] `.gitignore` に従ってゴミファイルは除外？
- [ ] 1コミット1目的？

#### **4. テスト**
- [ ] 手動で動作確認済み？
- [ ] LinearのIssue内容と一致？

#### **5. 命名・構造**
- [ ] クラス名・メソッド名は `coding-style.md` 準拠？
- [ ] 不要なコードは削除済み？
